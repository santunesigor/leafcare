# Amostras de verificação

- `reference_frog_eye.jpg`: uma imagem real de referência, recortada da figura 4
  de Lin et al. (2024). **Não é uma amostra de teste independente nem comprova
  identificação correta.** Consulte a atribuição. Não foi usada para treinar
  um classificador de doenças nesta entrega.
- `preprocess_golden.json`: pixels RGBA sintéticos e hash do resultado esperado
  de redimensionamento. Serve somente para comparar Python/Kotlin.

A tela de ajuda usa ilustrações nativas de enquadramento. O aplicativo não
cria registros demonstrativos e não inclui nenhuma previsão fabricada.

O conjunto completo de referência e qualquer dataset de treinamento estão
fora deste repositório. Preserve os direitos de distribuição dos seus dados.
